Rescyo は、破損・フォーマット済み・一部読み取り不能になったディスク、メモリーカード、USB メモリからのデータ復旧を行う、無料のオープンソースツールです。単一のポータブル実行ファイルで Windows 7–11、Linux、macOS に対応します。

> **ステータス：プレアルファ。** まだリリースはありません。v0.1.0 がバイト単位の復旧検証に合格するまで、重要なデータには使用しないでください。

DMDE、R-Studio、UFS Explorer の無料オープンソース代替ソフトです。本プロジェクトは DMDE Software、R-Tools Technology、SysDev Laboratories とは一切関係ありません。DMDE、R-Studio、UFS Explorer は各所有者の商標です。

## 基本方針

- **復旧元には絶対に書き込まない。** 復旧対象のディスクは読み取り専用で開かれ、型によって保証されます（I/O 層に書き込み操作は存在しません）。復旧したファイルを同じ物理デバイスに保存することはできません。判定はドライブ文字ではなくデバイス単位で行います。
- **ファイルごとに正直に示す。** 復旧した各ファイルについて、どのように組み立てたか（FAT チェーン、MFT ランリスト、または「連続」と仮定）と、内容の検証結果を表示します。
- **劣化したメディアをいたわる。** 読み取れないセクターは一度だけ読み、記録して二度と読み直しません。ディスクの劣化を検知すると停止し、先にイメージを取得するよう案内します。
- **入力は敵対的なものとして扱う。** ディスク構造の解析は `unsafe` を使わず、再帰・ループ・メモリ確保に厳格な上限を設け、すべてのパーサーをファジングします。
- **自動化を最優先。** すべての機能を CLI から利用でき、安定したバージョン付き JSON を出力します。

## v0.1 の予定

- FAT12/16/32、exFAT、NTFS：失われたボリュームの検出、フォルダーツリーの再構築、削除済みファイル
- ファイル数の制限なしでフォルダーツリー全体を復旧
- DMDE のスキャンログ（`devscan.log`）の取り込みによる再スキャンの省略
- 全ファイルの SHA-256 を含む JSON / CSV レポート
- 英語・ロシア語・簡体字中国語・日本語・韓国語の UI

以降のバージョンは[ロードマップ](docs/roadmap.md)を参照してください。
