Rescyo 是一款免费开源的数据恢复工具，用于从损坏、已格式化或部分无法读取的硬盘、存储卡和 U 盘中恢复数据。单个便携式程序即可运行于 Windows 7–11、Linux 和 macOS。

> **状态：预览前期（pre-alpha）。** 尚未发布任何版本。在 v0.1.0 通过逐字节恢复验证之前，请勿用于重要数据。

DMDE、R-Studio 和 UFS Explorer 的免费开源替代品。本项目与 DMDE Software、R-Tools Technology 及 SysDev Laboratories 无任何关联；DMDE、R-Studio 和 UFS Explorer 是其各自所有者的商标。

## 原则

- **绝不写入源磁盘。** 被恢复的磁盘仅以只读方式打开，并由类型系统保证：I/O 层没有写入操作。恢复的文件不能保存到同一物理设备上——按设备检查，而不是按盘符。
- **如实标注每个文件。** 每个恢复的文件都会说明其组装方式（FAT 链、MFT 运行列表或“连续”推测），以及内容校验是否通过。
- **保护濒临损坏的介质。** 无法读取的扇区只读一次并记录，不再反复读取；当磁盘状态恶化时，Rescyo 会停止并建议先制作磁盘镜像。
- **默认输入不可信。** 磁盘结构的解析不使用 `unsafe`，并对递归、循环和内存分配设有严格上限；每个解析器都经过模糊测试。
- **自动化优先。** 所有功能均可通过命令行使用，并提供稳定、带版本号的 JSON 输出。

## v0.1 计划

- FAT12/16/32、exFAT 和 NTFS：查找丢失的卷、重建文件夹树、已删除文件
- 恢复完整的文件夹树，不限制文件数量
- 导入 DMDE 扫描日志（`devscan.log`），无需重新扫描
- 包含每个文件 SHA-256 的 JSON 和 CSV 报告
- 界面支持英语、俄语、简体中文、日语和韩语
