# Rescyo

[English](README.md) · **Русский** · [简体中文](README.zh-CN.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

Rescyo — бесплатная программа с открытым кодом для восстановления данных с повреждённых, отформатированных или частично нечитаемых дисков, карт памяти и флешек. Один портативный файл для Windows 7–11, Linux и macOS.

> **Статус: пре-альфа.** Релизов пока нет. Не доверяйте ей важные данные, пока v0.1.0 не пройдёт проверку побайтного восстановления.

Бесплатная open-source альтернатива DMDE, R-Studio и UFS Explorer. Проект не связан с DMDE Software, R-Tools Technology и SysDev Laboratories; DMDE, R-Studio и UFS Explorer — товарные знаки их владельцев.

## Принципы

- **Никогда не писать на исходный диск.** Восстанавливаемый диск открывается только на чтение, и это гарантируют типы: у слоя ввода-вывода нет операции записи. Сохранить файлы на то же физическое устройство нельзя — проверка по устройству, а не по букве диска.
- **Честно про каждый файл.** У каждого восстановленного файла указано, как он собран (цепочка FAT, runlist MFT или предположение «непрерывно»), и прошла ли проверка его содержимого.
- **Беречь умирающие носители.** Нечитаемый сектор читается один раз, записывается в карту и больше не мучается; если диск деградирует, Rescyo останавливается и предлагает сначала снять образ.
- **Вход по умолчанию враждебный.** Структуры диска разбираются без `unsafe`, с жёсткими лимитами на рекурсию, циклы и память; каждый парсер фаззится.
- **Автоматизация в первую очередь.** Всё доступно из CLI со стабильным версионированным JSON.

## В планах v0.1

- FAT12/16/32, exFAT и NTFS: поиск потерянных томов, восстановление дерева папок, удалённые файлы
- Восстановление целых деревьев папок без ограничений на число файлов
- Импорт сканов DMDE (`devscan.log`), чтобы не сканировать заново
- Отчёты JSON и CSV с SHA-256 каждого файла
- Интерфейс на английском, русском, упрощённом китайском, японском и корейском

Следующие версии — в [дорожной карте](docs/roadmap.md): GUI и TUI, ext4/HFS+/APFS/Btrfs, образы дисков с картой в формате ddrescue, RAID, поиск по сигнатурам с проверкой целостности, MCP-сервер для AI-агентов.

## Сборка

```sh
cargo build --release
```

Бинарник — `target/release/rescyo`. Сборки для Windows 7 используют закреплённый nightly, см. [CONTRIBUTING.md](CONTRIBUTING.md).
