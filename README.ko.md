# Rescyo 레스키오

[English](README.md) · [Русский](README.ru.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md) · **한국어**

> 이 번역은 기계 지원 초벌 번역이며 원어민 검수를 기다리고 있습니다. 개선 제안을 환영합니다.

Rescyo는 손상되었거나 포맷되었거나 일부를 읽을 수 없는 디스크, 메모리 카드, USB 플래시 드라이브에서 데이터를 복구하는 무료 오픈 소스 도구입니다. 하나의 포터블 실행 파일로 Windows 7–11, Linux, macOS에서 동작합니다.

> **상태: 프리알파.** 아직 릴리스가 없습니다. v0.1.0이 바이트 단위 복구 검증을 통과하기 전에는 중요한 데이터에 사용하지 마십시오.

DMDE, R-Studio, UFS Explorer의 무료 오픈 소스 대안입니다. 본 프로젝트는 DMDE Software, R-Tools Technology, SysDev Laboratories와 관련이 없으며, DMDE, R-Studio, UFS Explorer는 각 소유자의 상표입니다.

## 원칙

- **원본에는 절대 쓰지 않습니다.** 복구 대상 디스크는 읽기 전용으로 열리며 이는 타입으로 보장됩니다(I/O 계층에는 쓰기 연산이 없습니다). 복구한 파일은 같은 물리 장치에 저장할 수 없으며, 드라이브 문자가 아니라 장치 단위로 확인합니다.
- **파일마다 정직하게.** 복구된 각 파일이 어떻게 조립되었는지(FAT 체인, MFT 런리스트, 또는 "연속" 추정)와 내용 검증 결과를 표시합니다.
- **죽어 가는 매체를 아낍니다.** 읽을 수 없는 섹터는 한 번만 읽고 기록하며 다시 읽지 않습니다. 디스크 상태가 나빠지면 Rescyo는 멈추고 먼저 이미지를 만들라고 안내합니다.
- **입력은 기본적으로 적대적이라고 가정합니다.** 디스크 구조는 `unsafe` 없이 재귀·루프·메모리 할당에 엄격한 제한을 두고 파싱하며, 모든 파서는 퍼징됩니다.
- **자동화 우선.** 모든 기능을 CLI에서 사용할 수 있으며, 안정적이고 버전이 붙은 JSON을 출력합니다.

## v0.1 계획

- FAT12/16/32, exFAT, NTFS: 손실된 볼륨 검색, 폴더 트리 재구성, 삭제된 파일
- 파일 개수 제한 없이 폴더 트리 전체 복구
- DMDE 스캔 로그(`devscan.log`) 가져오기로 재스캔 생략
- 모든 파일의 SHA-256이 포함된 JSON 및 CSV 보고서
- 영어, 러시아어, 중국어 간체, 일본어, 한국어 인터페이스

이후 버전은 [로드맵](docs/roadmap.md)을 참고하십시오.
